# Plan: Lưu trữ File Word/Ghi âm vào Database + MinIO

## Mục tiêu

Lưu trữ file Word và ghi âm theo mô hình:
1. Upload docx → Tách thông tin căn lề, giãn dòng, font...
2. Tạo 2 bảng mới: `chat_files` + `format_metadata`
3. Lưu file gốc + markdown đã parse vào MinIO
4. Gắn với `chat_id`, `user_id`

## Thiết kế Database

### Bảng 1: `chat_files` (lưu quan hệ file ↔ chat)
```
chat_files
├── id                       UUID, PK
├── session_id               UUID, FK → chat_sessions.id
├── user_id                  UUID, FK → users.id
├── file_name                str (tên file đã lưu)
├── original_filename        str (tên gốc khi upload)
├── file_type                str ("docx" | "audio" | "mp3" | "wav"...)
├── file_size                int (bytes)
├── minio_original_key       str (key trong hrag-uploads bucket - file gốc)
├── minio_markdown_key       str (key trong hrag-markdown bucket - markdown)
├── markdown_content         text (nội dung markdown đã parse)
├── report                   text (báo cáo kiểm tra định dạng, nullable)
├── issues_count             int (số vấn đề phát hiện, nullable)
├── created_at               datetime
```

### Bảng 2: `format_metadata` (lưu thông tin định dạng docx)
```
format_metadata
├── id                       UUID, PK
├── chat_file_id             UUID, FK → chat_files.id
├── format_data              JSONB (lưu toàn bộ thông tin căn lề, font, spacing...)
├── created_at               datetime
```

**Lưu ý**: `format_data` là JSONB column, linh hoạt thay đổi, có thể chứa:
```json
{
  "margins": { "top": 2.0, "bottom": 2.0, "left": 3.0, "right": 2.0 },
  "line_spacing": [...],
  "font_samples": [...],
  "page_size": { "width": 21.0, "height": 29.7 },
  "paragraph_count": 50,
  "table_count": 2,
  "has_header": true,
  "has_footer": false,
  "styles_used": ["Normal", "Heading 1"]
}
```
