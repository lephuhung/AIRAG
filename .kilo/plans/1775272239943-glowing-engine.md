# Plan: Hiển thị file đính kèm trong chat history

## Mục tiêu
Khi reload chat, hiển thị lại các file đã attach ở các tin nhắn trước đó (không chỉ trong session hiện tại).

## Tình trạng hiện tại
Đã hoàn thành phần backend lưu `document_ids` vào `chat_messages`:
- Backend đã lưu `document_ids` vào DB ✅
- Backend đã trả về `document_ids` trong API ✅
- Frontend đã map `document_ids` sang `documentIds` trong message ✅

## Cần làm

### 1. Frontend: Fetch metadata cho document IDs trong history

**Vấn đề:** Khi load chat history, `documentIds` đã có trong message nhưng chưa có `filename`, `status`, `file_type`... để hiển thị.

**Thêm state và hook:**
- Thêm `docMetadataMap: Map<string, Document>` trong `ChatPanel`
- Trong `useEffect` sync history (line 1929), sau khi map xong messages, collect tất cả unique `documentIds`
- Gọi `useDocuments(workspaceId)` để lấy metadata cho các docs đó, lưu vào `docMetadataMap`

### 2. Frontend: Tạo component `FileAttachmentBadge`

Tạo component nhỏ hiển thị file đính kèm trong message bubble:

```tsx
interface FileAttachmentBadgeProps {
  doc: Document;
}
```

Component sẽ hiển thị:
- Icon theo file_type (PDF, DOCX, etc.)
- Tên file (filename)
- Status badge nếu đang xử lý (`parsing`, `indexing`...)

### 3. Frontend: Render `FileAttachmentBadge` trong `MessageBubble`

Trong `MessageBubble` (line ~1254-1257), sau content của user message:

```tsx
{isUser && message.documentIds && message.documentIds.length > 0 && (
  <div className="flex flex-wrap gap-2 mt-2">
    {message.documentIds.map(docId => (
      docMetadataMap.get(docId) && 
      <FileAttachmentBadge key={docId} doc={docMetadataMap.get(docId)!} />
    ))}
  </div>
)}
```

### 4. Frontend: Thêm translation keys (nếu cần)

Thêm i18n cho các trạng thái file trong `en.json` / `vi.json`.
